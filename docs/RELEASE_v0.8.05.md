# ComfyHub v0.8.05

## 新增
- 向导「Python 环境」下拉来源三分标签：[共享] / [实例自带] / [自定义]，解释器路径行彩色分类 chip 实时同步，共享 Python 与实例自带不再混淆。
- 下拉「➕ 选择新增」入口：可浏览添加任意 Python 解释器（如其他实例的 python_embeded），自动分类、查重、取消自动回退。
- 设置页新增「目录」组：便携 Python/MinGit 工具安装目录可自定义（留空=默认，拦截相对路径）。

## 优化
- 便携 Python 安装/重装统一到「解释器路径」一行管理：默认或自定义路径皆可，重装自动识别共享位置、先卸旧再装新。
- 添加已有实例固定优先使用 ComfyHub 共享 Python；全无解释器时引导「下一步：修复」一键补装共享环境。
- 侧栏 logo 改用 256px 源图按 DPI 渲染，修复放大模糊。

## 修复
- 修复共享 Python 已安装时「重新安装」选项形同虚设的问题。
- 修复重装后复验永远缺失、安装流程死循环的链路。
