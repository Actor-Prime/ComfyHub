## 新增
- **保存前改动确认**：「系统设置」和「ComfyUI 实例设置」点保存时，先弹出改动清单（字段：旧值 → 新值），确认才写入；点「取消」一个字节都不动——防止不小心改了某项配置又忘了改哪，无感存进错误值
- API Key 在清单里只显示「已修改 / 已清除」，绝不回显明文；助手设定等长文本只显示字数变化

## 优化
- 所有页面在自定义背景图下统一加了半透明底板（此前只有 AI 助手页有），逐页滚动验证可读性
- 无改动时点保存不再写盘，底栏提示「没有改动，无需保存」；取消时提示「已取消，未保存任何修改」
- 设置页保存成功后不再弹「设置已保存」弹窗，底栏时间戳即反馈

## 说明
- 改动清单按字段聚合（如「生成引擎」一组），布尔项显示 开/关，长路径截断显示
