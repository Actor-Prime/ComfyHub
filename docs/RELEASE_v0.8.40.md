# ComfyHub v0.8.40

0.8.39 让 ComfyHub 能「连上」远端和云镜像，但只能读和跑图；这一版补的是「管起来」——启动、停止、建隧道、开关云主机、清缓存，都在同一个界面里。

## 新增：远程启动 / 停止（SSH）

远程实例的「启动 / 停止」不再是灰的。

- 实例设置里多一个「🛠 远程运维」页签，只有远程实例看得到。填主机、端口、用户名、认证方式（**密码或密钥文件都支持**，都可用），点「测试 SSH」先验通。
- 启动 / 停止执行的是**可编辑的命令模板**，预填了常见写法（`nohup python main.py ...` / `pkill -f "main.py --listen"`）。不同镜像目录不一样，直接改命令比猜路径可靠。
- **命令返回 0 不算启动成功**。真正的判据是轮询 `/system_stats` 到就绪，最长等 5 分钟；超时会附上远端输出的最后 20 行，方便判断是卡在装依赖还是显存不够。
- 如果实例本来就在跑，会明确说「实例已在运行（未执行启动命令）」，不会把你这次点击报成「启动成功」。
- 命令输出实时滚动（和「插件依赖补装」同一个对话框），**关掉对话框不会中断任务**，日志同时写进「控制台」页。

失败会分七类说清楚，不是一句「连接失败」：连不上 / 密码错 / 私钥口令错 / 远端拒收密钥 / 密钥文件读不到 / 主机指纹变了 / 需要 sudo 交互。

**主机指纹**：首次连接自动记录，之后变了就拒绝并提示可能是中间人攻击。存在 ComfyHub 自己的目录里，**不读也不改你的 `~/.ssh/known_hosts`**。

## 新增：内置隧道（一键，不用敲 ssh -L）

只给 SSH、不给 Web 入口的平台（大多数云镜像），现在填三个数字就能连：本地端口（默认 8189）、远端主机（默认 `127.0.0.1`）、远端端口（默认 8188），点「建立隧道」。

- 断线自动重连，退避 1→2→4→8→16 秒，5 次失败后停下并明确报「重连失败已停止」，不会无限转圈。
- 隧道期间**不会改写你保存的地址**，只在运行期临时指向本地端口；断开自动回落。配置里永远是你填的那个原地址，不会被改乱。
- 状态灯会显示「（经隧道）」。退出程序时隧道自动关闭，不留后台进程。

## 新增：云平台开机 / 关机（HTTP 钩子）

只给 Web API、不给 SSH 的平台走这条路：填开机 / 关机请求的 URL、方法、请求头、请求体（JSON 会校验并报行号），ComfyHub 调完再轮询实例地址到就绪。

内置 4 个**通用形态**模板（无鉴权 GET / JSON + Bearer / 表单 POST / 通用）：模板只是骨架，**平台实参请按平台 API 文档核对**，界面里也写了这句。

需要说明的是：平台返回 200 只代表「请求已受理」，不代表机器已经起来。界面文案是「平台已受理，等待实例就绪」，不会把 200 说成「已启动」。

⚠️ 请求头里的密钥是**明文保存在配置文件**里的（不像 SSH 密码那样加密）。建议用专用的、可随时吊销的 Token。界面里有一行提示说明这点。

## 新增：远程产物清理

远程出的图会下载到 `%LOCALAPPDATA%\ComfyHub\remote\<实例名>\`，久了会占满盘。设置页新增「远程产物」分组：

- 列出每个实例的文件数与占用，含总计；统计在后台线程做，不卡界面。
- 手动清空单个实例或全部，二次确认里写明「删的是本地副本，远端原图不受影响；下次看这张图会重新下载」。
- 自动清理可选：保留最近 N 天（默认 30）或总量不超过 N GB（默认 10），**默认关闭**。从最旧删起，跳过 1 小时内改过的文件和下载中的 `.part`，被占用的跳过并报数量。
- 实例删了但目录还在的，显示「（已删除的实例）<目录名>」，也能清。

## 新增：「＋ 添加 ComfyUI」现在能新建远程实例

以前这个按钮只能进本机安装向导，想建远程实例只能先建本机实例再改「连接方式」，或手改 `config.json`。现在点开是两个选项：**新建本机实例…** / **添加远程实例…**。

## 新增：http 明文告警

远程地址是 `http://` 且不是本机时，保存配置和连接成功会提示一次「流量未加密，Token 和生成的图会被同一网络的人看到」，可以按实例勾选「不再提示」。

隧道是加密的，所以**隧道激活时不会告警**——否则隧道用户会被自己该忽略的警告反复打扰。

## 修复

- **保存确认框会把旧 SSH 密码 / 密钥口令打成明文**（安全问题，本版引入）。0.8.40 把这两个字段做成「留空 = 保持原值」后会在装载时回填，而确认框只脱敏了新值、没脱敏旧值，于是修改密码时旧口令原文显示在屏幕上。现在新旧两侧都是「（已设置/已更新，不回显）」。
- **英文模式下「远程运维」页签大量中文残留**。根因不是缺词：`QComboBox` 选项、`QPlainTextEdit` 占位符、按钮 tooltip 三类控件不在语言切换的扫描范围，另有 11 处运行期文案没走翻译函数。另修了 SSH 失败提示的 9 段长文案——原来把主机名拼进句子再查词表，永远匹配不上，改成「先翻模板再填空」。
- **`pre_ready` 状态被忽略**，实例本来就在跑时仍然提示「已就绪」。

## 其他

- 打包脚本支持 `CI=1` 无人值守（不再卡在 `pause`）。
- `--upx-exclude` 明确排除 `_rust.pyd` / `_bcrypt.pyd` / `libcrypto-*.dll`。UPX 压缩 Rust 扩展会导致打包版启动即 `DLL load failed`，而这三个文件没有 CFG 标志，PyInstaller 的自动保护对它们不生效。
- 打包脚本的 `rem` 注释改成纯 ASCII：cmd 按 936 码页重读批处理时，UTF-8 中文可能被解出 `&`/`|` 把注释劈成命令，断点正好落在三条 `--upx-exclude` 旁边。

## 升级说明

- 安装包 **41.6 MB**（0.8.39 是 43.0 MB，反而小了 1.4 MB：新增的加密组件压缩率高，NSIS 整块压缩把重复符号吃得更干净）。首次启动内存占用约 180 MB。
- 安装包未进入公共信任链（自签名），SmartScreen 会警告一次，选「更多信息 → 仍要运行」即可。
