# ComfyHub v0.8.25

## 新增
- 工作台显卡卡显示实时显存占用（已用/总量 + 占用率进度条，驱动与 torch 建议收进悬浮提示）
- 工作台磁盘卡显示当前实例所在硬盘的剩余空间（盘符自动识别，不再写死）

## 优化
- 插件市场热度数据过期时先显示缓存结果再后台刷新，连续 8 页失败自动熔断，不再卡「获取中」
- 插件安装完成后弹出「安装完成」提示，并同步刷新已安装列表与市场按钮状态（变「已安装 ✓」）
- Git URL 安装完成与市场安装统一走弹窗提示；卸载完成后市场按钮同步变回「安装」

## 修复
- 修复环境对话框卡「准备 0%」不动的问题（修复线程挂载后未启动）
- 下载中断后重试不再清空已下载进度，断点保留原地续传
- 修复自更新过程弹出命令行黑窗、批处理自删报错与残留提示符
- 卸载插件不再弹出 CMD 黑窗（回收站操作改为无窗口执行）
