# ComfyHub v0.8.23

## 新增

- AI 助手消息改为圆角描边卡片，正文宽度随窗口缩放自适应。
- 模型库支持双击跳转：类别行直接下钻到该类别，文件行在资源管理器中定位。
- 识别 ComfyUI 的 extra_model_paths.yaml，外部挂载的模型库并入统计与列表。
- 工作台「实例信息 + 目录网格」加圆角外框，内容收拢成块。

## 优化

- 自定义背景下分组框 / 卡片 / 输入框统一加半透明描边与圆角，边界由线条定义、不再靠色差。
- 实例设置「模型目录」真正生效：启动时传 --models-directory，模型库与 AI 工具同步跟随。
- 纯文字控件（表单字段名、复选框）不再带面板底色，直接融入背景。

## 修复

- AI 助手页消息行出现整行深色横带、历史消息宽度被钉死在旧尺寸的问题。
- 分组框标题与边框线交叠的问题（标题挪到框线上方）。
- 工作流页刷新键与实例页多个窄按钮图标显示不全（内边距挤压内容区）。
- AI 帮忙启停实例后，顶部状态点不及时刷新的问题。
