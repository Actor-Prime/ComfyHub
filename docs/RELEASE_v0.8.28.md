# ComfyHub v0.8.28

## 新增

- AI 服务商新增「Token/编程套餐」分组：内置智谱 GLM Coding Plan（国内 / 国际）、Kimi Code 会员（国内 / 海外）、阿里百炼 Coding Plan（国内 / 国际）与 Token Plan、火山方舟 Coding Plan、腾讯云 Coding Plan、MiniMax Token Plan 共 10 个订阅制端点，套餐 Key 直接可用。
- AI 助手页右侧新增「概要」抽屉：贴边把手点开即可查看当前对话的简介（用途 / 实例 / 工作流 / 模型 / 消息数 / 压缩摘要）、产物（生成的图、写出的工作流、下载的模型、日志）与技能正文，展开状态自动记忆。
- AI 助手触发的模型下载会进入模型库的下载中心：任务行带 AI 徽标、状态栏提示进度位置，下载结束自动刷新模型列表。

## 优化

- 下载任务面板按字体与屏幕尺寸自适应宽度（420~640），任务多时内部滚动，长文件名与失败原因不再溢出被裁。
- 下载面板支持按内容高度贴合，任务少时不留大片空白；任务行新增来源徽标与更紧凑的按钮。
- AI 报错改为「人话 + 下一步动作」：401 / 403 / 404 / 429 / 402 / 400 / 5xx 与超时、连接被拒、DNS 失败、证书拦截各有对应说明，服务端返回的原始原因附在末尾。
- 设置页「测试接口」的失败提示同步换成人话（单行版）。
- 消息正文宽度预算修正，窄窗口下不再每行少放几个字。

## 修复

- 修 AI 助手跨线程入队导致下载任务不显示在下载面板的问题（后台线程创建控件不被布局接管）。
- 修认证失败（401）被包装成「等待模型响应超时」而误导排查方向的问题。
- 修模型库底部日志区在矮窗口被压到零高、多行日志叠在一起的问题。
- 修空会话重复显示两张欢迎卡片的问题。
- 修 MCP 模式（无界面）下下载模型调用不存在的参数导致崩溃的问题。
