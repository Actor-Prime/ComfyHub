## ComfyHub v0.8.11

### 新增
- AI 助手页：对话式管理实例，16 个工具覆盖体检/日志/队列/模型/工作流，支持流式输出
- 图生图闭环：粘贴参考图 → 提炼风格 → 改工作流副本 → 出图，全程自动
- JSON 出图：粘贴工作流 JSON（UI/API 格式均可）→ 按描述改提示词 → 出图
- 思考强度与上下文可调，按模型族自动映射厂商参数（MiMo/GLM/Qwen/OpenAI 等）
- 外部 Agent 接入：`ComfyHub.exe mcp` 以 MCP 协议暴露同一套工具
- 版本更新：Gitee 主源 + GitHub 备用，SHA256 与签名双重校验，静默安装/便携自替换

### 优化
- AI 响应：关思考 + 上下文可调 + 工具结果裁剪，实测首字 2.1s、全文 6.1s
- AI 页新版式：整宽卡片 + 工具调用时间线 + Markdown 渲染 + 附件缩略图
- 实例下拉对目录不存在的实例标注「⚠ 目录不存在」，顶部状态点实时探测端口

### 修复
- 修同 id 重复实例导致选中/删除串台，配置加载时自动自愈
- 修附件删除按钮不可见（字符图标改为系统标准图标）
- 修多行文本被裁、Markdown 星号原样露出
- 修连接被拒绝等网络错误把 Python 调用栈直接抛给用户

### 修复（v0.8.11 补充）
- 修静默安装未结束运行中进程，导致覆盖失败、装成"新内核+旧主程序"的半破状态
- 升级改为等主程序退出后再启动安装器，避免文件占用
