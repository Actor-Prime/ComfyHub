# ComfyHub v0.8.38

## 修复

- **AI 助手页两侧不再有两条空白带**：原来是「留白 + 会话栏 + 限宽 1520 的聊天区 + 右侧抽屉 + 留白」，2560 屏上左侧空 341 px、右侧空 194 px，会话栏和右抽屉整块浮在屏幕中间，看着像没铺满。现在三栏全部由布局拉满：左会话栏紧贴左侧导航条，右抽屉紧贴窗口右边缘，任意窗口宽度下都不会再出现贯穿上下的空白带。
- **正文列改在聊天区内部限宽 1560 并居中**：窗口再宽也不会把一行字拉成横跨整屏（1980 以上屏原来的老问题），窗口变窄时这一列自动跟随宽度、不挤压中栏内容。

## 改进

- 三栏与聊天区之间只保留 10 px 常规间距，面板圆角与底色连续，不再出现「浮在中间的卡片」观感。

---

建议所有在 2K / 4K 宽屏上使用的用户升级：0.8.37 及更早版本在这一页左右各会空出一条明显空白。
