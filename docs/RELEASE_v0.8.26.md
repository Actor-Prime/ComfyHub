# ComfyHub v0.8.26

## 新增
- AI 助手支持会话级技能：输入区「⚙ 会话设定」勾选本对话启用的技能，不同对话各挂各的
- 出厂内置 3 个技能（提示词优化 / 报错诊断 / 工作流调参），也可自行放 markdown 到技能目录扩展
- AI 助手改为左侧常驻会话列表栏，新建 / 切换 / 右键重命名删除，一键折叠
- 会话工作台：一条对话固定绑定用途、实例、默认工作流、默认模型与技能，互不串台
- 助手反问时消息下方弹出可点选项按钮，点击即作为回复发送

## 优化
- 会话列表直接显示每条对话的用途标签（如「H3 视频」「Qwen 生图」），多条对话一眼分清
- 已绑定工作流时，出图/跑片未指定工作流会直接使用绑定项，不再反复列目录挑文件
- 新对话可「以此工作台新建」，同用途多会话无需重复配置
- 进入对话即展示当前工作台配置，知道自己处在哪个用途的会话里

## 修复
- 手动重命名的对话不再被首条消息自动生成的标题覆盖
- 只配置了会话设定、还没发消息时也会保存，切换对话不会丢失配置
- 切换对话时待发附件、待选选项与技能一并清空，不再互相串台
