# ComfyHub v0.8.36

## 修复

- **更新完成后程序不自动打开**：自更新走的是静默安装，而静默模式不显示任何页面，安装器「完成页 → 运行 ComfyHub」那个勾选项永远不会执行 —— 于是更新跑完，被关掉的程序再也没人拉起来。现在更新脚本用环境变量 `COMFYHUB_LAUNCH_AFTER` 告诉安装器「装完自己启动新版本」，安装器在成功回调里等 600 ms（让文件句柄彻底释放）再启动。
- **更新提示条那一行文字显示不全**：全局按钮样式给了 `padding: 7px 15px`，而提示条把按钮压到 26 px 高，内容区只剩 26−14−2 = 10 px，12 px 中文的行高是 15 px，上下各被削掉 2~3 px。右边那个 ✕ 更明显 —— 固定 24 px 宽碰上左右各 15 px 内边距，整个字被压没了。现在提示条内按钮单独覆盖内边距（颜色、边框、强调蓝底仍走全局主题，深浅主题翻转不受影响）。
- **插件加载失败提示条同样的问题一并修掉**：它的「一键补装 / 日志 / ✕」也是 26 px 高，命中同一个坑。
- **「添加 ComfyUI」不再一打开就锁到 F 盘**：向导第 1 页的默认路径原来写死 `F:\ComfyUI`，而且打开向导就全盘探测、命中即填入并开始验证 —— 机器上装了官方 ComfyUI Desktop 的用户，点「添加」直接被带到 `F:\Comfy-Desktop\ComfyUI-Installs\ComfyUI\ComfyUI`，想新建一个独立环境都没机会。现在默认恒为「程序目录\ComfyUI」的全新安装，探测到的现成实例只进下方候选下拉（默认仍选「新建新实例」），想接管已有环境的人才去点它。
- 修 `updater.py` 里 cmd 脚本模板的几处非法转义（`\Software` / `\Programs` / `\ComfyHub.exe`），Python 3.12+ 会为此报 SyntaxWarning，将来会变成硬错误。
- **安装向导的「完成 / 返回 / 取消」不再是英文**：Qt 的 `setFinalPage()` 会把 QWizard 自带按钮文案重置回英文（`Finish` / `Back` / `Cancel`），而我们只在中文化过一次 —— 只要切过一次页面状态就全变英文了。现在每次切 finalPage 都重套一遍中文（Next 键不动，它的文案归状态机管）。
- **首次安装后点「保存设置」不再弹「本次将保存 14 处修改」**：新装的 `config.json` 里还没有 `settings` 这些键（用户从没设置过 ≠ 空值），而差异比较把它们全当成了「(空) → 默认值」的改动 —— PyPI 镜像、主题、本地模型、背景缩放…… 十几条全是假的。现在设置页记一份「控件刚建好时」的状态当基线，老配置缺键或存空值时拿它比较：没动过就没有改动，点保存直接提示「没有改动，无需保存」。
