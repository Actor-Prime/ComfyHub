## 新增
- **工具轮数用尽不再硬停**：AI 助手连续多轮调用工具后，会再跑一轮「强制收尾」——不带工具，让模型直接总结「已查到什么 / 还缺什么 / 建议怎么问」，不再只丢一句「任务可能过于复杂，已停止」

## 优化
- **重复调用护栏**：同一工具 + 完全相同的参数第 3 次起，自动向模型注入提示「结果不会变，请换参数或直接作答」，避免 8 轮全耗在一个查不到的搜索上
- **模型搜索空结果给建议**：`search_models` 搜不到时返回改用英文品牌词（qwen / flux / wan / sd3）的提示，并建议先看本地模型列表

## 修复
- 工具收尾轮不再携带空 `tools` 数组（部分接口会因此报错，导致收尾失败退回红字报错）
