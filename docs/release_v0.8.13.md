## 新增
- **出图结果三重校验**：AI 报出图前逐个验证文件——`images`（真实存在且本次新写）/ `stale_images`（命中 ComfyUI 缓存，没生成新图）/ `missing_images`（号称有但磁盘没有），三类分别返回，杜绝「说出图完成但文件夹里没有」
- **图片点击预览**：AI 页里上传的图片与生成结果缩略图，点击即弹出大图（显示分辨率，点击任意处或按 Esc 关闭）

## 优化
- AI 工具 `patch_workflow` 参数容错：工作流名支持 name / workflow / workflow_name / file / filename 五种写法；`ops` 传单个对象自动包成数组，误传字符串时直接给出正确格式示例；缺工作流名时列出目录中真实可用的文件名
- 工具报错去掉 `ValueError:` 之类类型前缀，改为可直接照做的中文提示
- 系统提示词新增硬规则：只逐字复制工具返回的图片路径，禁止自行推算文件名或编号

## 修复
- AI 页工具上下文未传主窗口，导致界面上点「帮忙启动实例」被误判为 `--mcp` 外挂模式而拒绝执行
- 出图缩略图只设了手型光标、点击无响应
