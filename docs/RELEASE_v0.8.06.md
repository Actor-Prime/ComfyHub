# ComfyHub v0.8.06

## 新增
- 启动模式管理：内核源码快照与回滚、工作流导入自动建启动模式、启动参数拼参引擎、模式体检（缺失节点类一目了然）。
- 模型市场多源搜索与分页：Comfy-Org 官方仓库 + ModelScope 国内源 + HF 镜像轮换，「加载更多」与滚动到底自动续页。
- CivitAI 模型文件行三路下载：直链下载、复制直链、HF 镜像多策略同步仓库。
- 关闭按钮三态：首次点击询问「退出 / 最小化到托盘」且可记住选择，设置页随时改「每次询问 / 直接退出 / 最小化到托盘」。
- 核心节点反查：扫描工作流自动识别内置核心节点并提示所需内核版本，不必再去插件市场找。
- AI 兜底开关：可选接入 OpenAI 兼容 API 辅助识别未知节点/模型（域名白名单，结果标注「待验证」）。
- 代码签名链：打包脚本集成条件式签名（自签证书 + DigiCert 时间戳），换正式证书零改动。

## 优化
- 便携 Python / MinGit 下载改断点续传多源轮换，大包断连自动续传不再从头再来。
- 控制台「安全删除」过程噪声降噪，关键日志更清爽。
- 打包脚本模块化：build_exe / build_installer / sign 独立可用，签名未配置时自动跳过不挡道。

## 修复
- 修复 torch CUDA 安装链三处问题：损坏误判、静默回退 CPU 版、大包下载断连失败。
- 修复扫描识别与下载中心若干实测问题，插件名列截断悬停看全文。
