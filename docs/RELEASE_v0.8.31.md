# ComfyHub v0.8.31

## 新增

- 工作流模板库：内置官方工作流模板（文生图 / 图生图 / 文生视频等），新建实例后可直接从模板库挑一个开跑，不用自己连线；也支持把自己的工作流存为模板。
- 本地模型支持视觉理解：本地部署的 Qwen3-VL-2B 可直接看图（截图诊断、看工作流报错截图），模型清单与下载页同步更新。
- 可选组件（llama.cpp）：环境管理页新增可选组件区，一键安装 / 更新 llama.cpp 推理后端，用于本地模型加速，不装不影响原有功能。
- AI 助手「助手设定」默认值改为「按工作流实际需求」：不再写死分辨率 / 步数 / 采样器，模型自己看工作流里每个节点要什么；另加一句技能设定，优先走节点推荐值。
- 网页搜索工具：AI 助手可联网查资料回答问题（结果附来源链接）。
- 新增 toast 轻提示组件：操作成功 / 失败用底部浮条提示，不弹窗打断。

## 优化

- AI 助手坏工具参数三层修复：工具参数不合法时先回填校验、自动重新生成参数再执行，不再直接甩一串原始 JSON 报错；错误提示改成人话（说明哪个参数错、期望什么格式），日志按 notice 分流不刷屏。
- AI 助手现在能直接读写 API 格式工作流（`{节点id:{class_type,inputs}}`）：inspect / patch 两件套覆盖 API 导出的工作流，此前只能处理 UI 格式。
- 子图（subgraph）工作流支持完善：子图内部纯 widget 输入（提示词 / 模型名 / seed 等）即使没显式连线也能取到值，取值顺序为 `widgets_values` 数组优先、`widgets_values_named` 兜底；可选输入（如首尾帧）未连线时按前端同款省略不传，不再报「未连线」错误。
- AI 生成的视频 / 图片历史按时间线展示，支持预览与重发。

## 修复

- 修子图边界输入未连线导致工作流提交必失败的问题（提示词、模型选择等 6 个纯 widget 输入）。
- 修 SaveVideo 等节点 `format` 字段（`COMFY_DYNAMICCOMBO_V3` 类型）不被识别、提交报 missing 的问题；确认 `COMFY_MATCHTYPE_V3` / `COMFY_AUTOGROW_V3` 是连接口，不误当 widget。
- 修 patch 工作流时只改 `widgets_values` 数组、不同步 `widgets_values_named` 导致两份数据分叉、下次读取取回旧值的问题。
- 修 AI 助手状态栏本地模型红点误报、消息 Type 双发等细节问题。
