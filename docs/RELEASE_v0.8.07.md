# ComfyHub v0.8.07

## 新增
- 界面主题四档：深色 / 浅色 / 跟随系统 / 自定义（面板半透明 + 自选背景图，保存即生效）。
- 中英双语切换（静态界面文案全量覆盖，首次开启 English 需重启）。
- 设置页「AI 接入」升级：一键「测试接口」自动拉取模型清单并绑定，自动跳过语音类模型。
- 工作流页「🤖 AI 补全并执行」：把「升级内核 → 装插件 → 下载模型」合成一条队列一次跑完。

## 优化
- 打包脚本内置签名链，出包即自动签名（含时间戳），不再需要手动补签。
- 主题切换改为幂等缓存，重复创建窗口从秒级降到 0.14 秒。
- AI 兜底调用加限流：单次扫描最多 6 项、单次超时 25 秒，避免批量扫描被网络拖死。
- 设置页「自定义背景」两行改为紧贴主题选择器内联展示。

## 修复
- 修复推理型模型（如 mimo-v2.6）思维链吃光 token 导致 AI 返回空结果的问题。
- 修复点任务栏最小化被误收进托盘；现在只有关闭按钮选「最小化到托盘」才变托盘图标。
- 修复关闭询问框「记住我的选择」后设置页下拉不同步的问题。
- 修复打包脚本两处缺陷：缺签名链、进程退出误判为「未能关闭」。
