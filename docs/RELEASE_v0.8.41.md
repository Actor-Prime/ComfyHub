# ComfyHub v0.8.41

上一版（0.8.40）补的是远程的「管起来」，这一版只做一件事：把「局域网访问」这类**改完不立刻生效**的设置讲清楚——保存的时候告诉你哪些改动需要重启，别让你白等一场。

## 本次更新：改完会提示要不要重启

「局域网访问」是上一版新增的开关，但 ComfyUI 的 `--listen` 只在**实例启动时绑定一次**。以前的流程是：勾选 → 点保存 → 只弹一句「✅ 设置已保存」，你以为局域网马上就能访问了，实际地址栏里还是连不上，得自己想起来重启一遍。

现在保存时会看一眼实例状态：

- **实例正在运行**，且这次改动里包含「启动才生效」的字段 → 保存确认弹窗会追加一段「⚠️ 以下改动需重启实例才生效…」，并**逐项列出改了哪几项**（比如「局域网访问」「端口」），一眼就知道要重启的是什么。
- **实例没在运行** → 弹窗保持原样，不打扰你——本来下次启动就会带上新配置，没必要多说一句。

另外，把鼠标悬停在「局域网访问」选项上也会看到提示：「该选项在实例启动时生效，实例运行中修改后需重启实例才能生效。」改之前就知道后果，不用等保存完才明白。

## 提示范围：不止局域网访问，共 21 项

需要重启才生效的不止「局域网访问」一个。**端口、显存模式、Cross Attention、精度、挂载模型目录、额外启动参数**等，一共 **21 项启动类配置**都在提示范围内——清单是按实例启动命令的构造逻辑逐字段核对出来的，不是凭印象列的。凡是只在启动时读一次的设置，运行中改了都会提醒你重启；运行期就能热生效的设置（比如地址、认证方式）不会被误报进去。

## 改进：保存流程更皮实

以前查询实例状态如果出异常，有可能连累保存本身失败。现在状态查询异常时**保存照常落盘**——「想弹个提示」只是锦上添花，绝不能反过来把你的设置弄丢。

---

只有在用「局域网访问」或多实例端口切换的用户能明显感觉到变化；其他用户升级后行为完全一致。
