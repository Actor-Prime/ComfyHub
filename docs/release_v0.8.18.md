## 安全
- **API Key 改为加密存储**：`config.json` 里的 `ai_api_key` 现在用 Windows DPAPI 加密（`enc:v1:...`），密文只能被**同一个 Windows 用户在同一台机器**上解密——文件被拷走、整目录打包分享都解不开
- **旧配置自动迁移**：升级后首次启动会把盘上的明文密钥就地加密，无需手动操作；迁移前后 AI 功能不受影响
- **解密失败不降级**：换了机器/用户导致解不开时，按「未填写」处理并打标记，绝不会把密文当 Key 发出去
- **诊断包加固**：除了「api_key=xxx」这类形态，现在还会把配置里真实的 Key 值做精确替换，日志里出现裸 token 也不会漏

## 修复
- 密钥原本明文存放在 `%APPDATA%\ComfyHub\config.json`

## 说明
- 加密用系统 DPAPI，不引入任何第三方依赖；便携版同理——把 `data\config.json` 拷到别人电脑上无法解密，不会泄漏你的 Key
- 内存中仍是明文（调用接口需要），只保证"落盘与传播"环节安全
