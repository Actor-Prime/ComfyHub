# ComfyHub v0.8.09

## 新增
- 内核版本列表分页加载：一次 20 条，底部「加载更多（还有 N 条）」按钮，滚动触底自动再加载 20 条。

## 优化
- 版本列表计数行标注数据来源（列表：origin/master），拉取失败时明确提示「远端拉取失败，以下为本地缓存」。
- 版本列表取数加深至稳定版/开发版各 200 条，翻页有得翻。

## 修复
- 修复版本列表读本地分支旧历史、更新时间停在旧日期与其他启动器对不上的问题（改读远端跟踪引用）。
- 修复开发版行「切换并装依赖」把提交标题当 git 引用导致切换必败的问题（改传提交短 hash）。
- 修复列表渲染与滚动自动加载重入冲突、行数与「还有 N 条」文案互相覆盖的问题。
- 修复侧栏导航英文不翻译、语言切回中文不生效、主窗标题漏翻三处本地化问题。
