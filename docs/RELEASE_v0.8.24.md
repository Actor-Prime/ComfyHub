# ComfyHub v0.8.24

## 新增

- 实例设置「模型目录」卡片加「启用挂载模型目录」开关，可选一个外部模型根目录并按标准子目录自动映射。
- ComfyUI 页新增「📚 共享外挂库」Tab：开关 + 挂载根目录 + 类别映射状态，一份挂载表所有实例通用。
- 模型库页新增「来源」筛选（全部 / 实例内置 / 外部挂载）与「来源」列，文件行双击可在资源管理器定位。

## 优化

- 系统设置只保留网络 / 目录 / 界面 / 关于，模型相关设置集中到 ComfyUI 页，避免同一件事两处维护。
- 保存设置改为「以界面加载时的取值为基准」比对新旧值，空字段即默认值不再被算成一次改动。
- 实例级挂载与共享外挂库叠加生效，两者各自独立，启动时一起传给 ComfyUI。

## 修复

- 左侧导航栏按钮可以被拖走、拖乱的问题（列表在图标模式下默认开放拖放与自由移动）。
- 老配置点「保存设置」弹出十几项「（空）→ 自动」虚假改动的问题。
- 窄图标按钮图标被内边距裁切、「模型目录」被误当作 --models-directory 覆盖用户配置的问题。
