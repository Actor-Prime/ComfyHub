## 1. ComfyUI管理大师 V3.6.0（AI搅拌手，收费会员制）

- **分析方式**：黑盒运行观察（2026-10-25 实测修正）——运行后 PrintWindow 截图 +
  进程枚举 + PE overlay 结构判定。**未反编译、未解包提取任何代码或素材**
- **技术栈判定**：97.6MB exe 为 NSIS+7z 自解压安装包；主进程 comfyui_master.exe
  单进程原生程序，**非 Electron**（与 ComfyUI-Desktop 不同层，与我们 PySide6 同层）
- **观察到的界面结构**（仅记结构概念，未取任何素材）：
  左侧竖向图标导航（设置/工具箱/工作流/模型/ComfyUI/工作台）+
  中部配置表单（分组 + 目录旁修复按钮）+ 底部多实例标签栏 + 底部状态栏
- **观察到的能力**：
  | 功能 | 我们是否实现 |
  |---|---|
  | 多实例管理 | ✅ 已实现（独立设计）|
  | 插件管理 / 批量更新 | ✅ 已实现 |
  | 环境快照 | ⏳ 计划中（自研版本清单方案）|
  | 工作流库 + 云端 requirements 清单 | ❌ 不做（依赖其云端服务）|
  | LoRA 训练集成（fluxgym）| ❌ 不做 |
- **明确未参考**：其代码、界面截图/图标/文案措辞、配置字段命名体系
- **我们的差异**：实例升为一等公民（顶部实例切换条，非底部小标签）、
  PySide6 更轻（46MB vs 94MB）、完全免费、全自动装环境

## 2. ComfyUI_TE模式启动器 1.0.0

- **分析方式**：PE 结构分析（`.text` 53KB + `.rsrc` 50MB = 自解压壳）+ 运行后读取其生成的
  `launcher_config.json`（**这是它自己写到磁盘上的配置文件，属公开可见数据**）
- **观察到的功能开关**（来自其配置文件字段名）：
  启动模式（插件组合）、工作流插件识别、重复插件检查、任务完成通知、
  性能开关（fp16 累加 / sage attention / 保留显存 / 多卡）、专家参数 26 项、
  浏览器选择、HF 镜像、主题、新手引导、VIP 授权
- **我们实现的部分**（均为独立设计）：
  | 功能 | 我们的实现方式 |
  |---|---|
  | 启动模式 | `plugin_profiles.py`：`{name, enabled[], args}` + journal 回滚（数据结构与它不同：我们带 args，且实例级隔离）|
  | 重复节点检查 | 静态正则解析 `NODE_CLASS_MAPPINGS`（**不 import 插件代码**）|
  | 任务完成通知 | HTTP 轮询 `/queue` + `/history`（**未用它的 websocket 方案**）|
- **明确未参考**：其 exe 内部代码（加密载荷，未逆向）、界面布局、文案措辞

## 3. 机智启动器（疑似 ComfyUI-Mie-Package-Launcher 1.0.0，作者 hiluo）

- **分析方式**：PE 结构（Nuitka + Enigma 封包，`.rdata` 29MB 加密载荷）+ 其公开 README
- **运行情况**：本机启动失败（无进程/无产物），**未获取任何运行时数据**
- **观察到的能力（来自公开文档）**：
  CLI 模式、内核版本管理、批量更新前端/模板库、批量任务 + 自动重启、启动器自更新、公告系统
- **我们实现的部分**（独立设计）：
  | 功能 | 我们的实现 |
  |---|---|
  | CLI 模式 | `app/cli.py`：argparse + 7 子命令 + 退出码契约（接口设计自定义）|
  | 内核版本管理 | `KernelManager`（git tag 切换 + 自动装依赖）|
  | 批量任务 | `batch_runner.py`：提交 /prompt + 轮询 /history + 定时重启 |
- **明确未参考**：其代码、CLI 参数命名、公告系统（不做）、自更新（计划自建 manifest）
