# ComfyHub v0.8.29

## 新增

- AI 服务商补充小米 MiMo Token Plan 三条订阅端点（中国 / 新加坡 / 欧洲），套餐 Key（tp- / ttp- 开头）现在能直接选到；同时修掉阿里 Token Plan 匹配键过宽、会把 MiMo 套餐域名误判成百炼的问题。
- AI 助手新增按会话技能收窄工具表：技能文件可声明 `<!-- tools: ... -->`，勾了技能就只带它需要的工具（19 个 → 8 个，纯文本技能只剩 3 个），工具定义少一半、模型更少选错。
- AI 助手新增 token 用量显示：右侧概要栏的「用量」一行给出本会话累计输入 / 输出与缓存命中率；服务商不返回 usage 时自动按字符估算并标注。
- AI 助手新增 `recall_history` 工具：压缩掉的早期对话原文会落盘，可用关键词回查，摘要之外还能捞回细节。
- AI 助手把本机环境画像（显卡与显存、torch/CUDA、ComfyUI 版本、磁盘余量、7 天内的崩溃摘要）写进 system 提示，排查时不必每次都先跑一遍体检。
- 会话侧栏新增搜索（覆盖标题、首条消息、用途 / 工作流 / 模型）与「仅当前实例」筛选。

## 优化

- 上下文压缩改为按模型窗口占比触发（中度档 85% 触发、保留 12% 原文），替换原先按消息条数的判据；摘要带实例名与时间戳，换实例后自动作废。
- AI 单轮请求失败会自动重试（超时 / 连接重置 / 5xx / 429，最多 2 次带退避），401 / 404 等配置问题照旧立即报错；已经输出正文后不再重试，避免同一段话重复两遍。
- 只读工具（体检、日志、队列、模型、工作流）同参数 30 秒内复用结果，任何写操作后自动失效，减少重复调用接口。
- 工作流节点清单不再被通用裁剪规则砍到 5 条，`inspect_workflow` 能拿到全部节点，便于定位报错节点。
- 更新检查开关改为主从关系：关掉「启动时自动检查」后，每小时检查也一并停用，不留后台偷跑。
- 弹窗里的「延后提醒」改为到点立刻弹（不再等下一次整点检查），「不再提醒」只在本次运行内静默、下次启动恢复提示。

## 修复

- 修日志结果裁剪从头部切割导致 traceback 尾部与报错行被丢弃的问题：改为保尾部并优先抢回含 error / traceback 的行，裁完仍是合法 JSON。
- 修 AI 助手触发启动实例时浏览器抢焦点、打断当前对话的问题（AI 启动不再自动打开网页，手动启动行为不变）。
- 修 `ai_compress` 默认值与设置页显示不一致（界面显示「中度」但实际未压缩）。
- 修空会话出现两张重复欢迎卡，以及窄窗口下正文每行少放几个字的问题。
