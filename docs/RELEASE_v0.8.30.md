# ComfyHub v0.8.30

## 新增

- 插件依赖自检与一键补装：环境管理页新增「插件依赖自检」，扫描各插件 `requirements.txt` 里缺的包并批量补装，补装时用 constraints 钉死已装版本，不会把 CUDA 版 torch 降级成 CPU 版。
- 启动后自动巡检插件加载日志：识别 IMPORT FAILED / ModuleNotFoundError 等四类失败，顶部弹出提示横幅，「一键补装」直接修，附「日志」跳转。
- 背景图亮度自适应：换图时自动采样明暗，偏亮图自动转浅色极性（米白底板 + 深色字），并按图里最坏的明暗局部自动抬高面板浓度，暗图亮图都能看清字。
- 背景图调整窗：选图后可直接拖动位置、滚轮以短边贴合为基准等比缩放，位置随图保存，随时可「调整位置…」重调。
- 设置页新增「背景模糊」滑杆（0~24px），模糊掉图片局部明暗差，配合低不透明度更好看。
- 从低版本升级后首次启动自动弹出「更新内容」：随包携带各版本 Release 说明并跨版本聚合（如 0.8.20 → 0.8.30 会列出中间每一版），离线可看。

## 优化

- 主窗口改无边框：去掉系统标题栏，页面标题、实例切换、添加实例与窗口控制合并为一条与内容区同色的标题栏，不再是两层横条；Win11 下窗口自带原生圆角。
- 窗口控制三键（最小化 / 最大化 / 关闭）改矢量图标，统一 12px 画布与 1px 线宽，跟随主题换色，不再因字号不同而大小不一。
- 工作台状态卡图标改矢量线稿：内存条 / 芯片 / 显卡 / 硬盘一眼可辨，替换掉原来的脑子、齿轮等不贴切 emoji。
- 浅色主题整体改暖米白（页面、卡片、凹陷三档色阶），大量半透明面板在浅色下重新配色，长时间看不刺眼；按钮补足色差更易辨认可点。
- AI 助手点击左侧会话自动落到最新一条，不再需要手动拖到最底；消息区宽度重做预算，长文本、代码块、出图都不再出现横向滚动条。
- 安装向导在装完 ComfyUI 核心依赖后自动补装 ComfyUI-Manager 依赖，新电脑首次安装不再因缺 `cv2` 等包导致插件加载失败。

## 修复

- 修工作流提交返回 HTTP 400 的问题：根因是共享 Python 缺插件依赖（cv2、gguf、accelerate、colour 等）导致相关插件 IMPORT FAILED、子图节点未注册，现在由依赖自检与向导补装两头堵住。
- 修配置文件被外部写坏（例如带 BOM 头）后静默回退默认配置、把用户设置覆盖丢失的问题：现在解析失败先留底 `config.json.bad_<时间戳>` 再回退，并兼容 BOM 文件自动读入。
