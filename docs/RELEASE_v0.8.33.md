# ComfyHub v0.8.33

## 新增

- **组件下载国内加速**：llama.cpp 组件包（25~38 MB）原来只从 GitHub Releases 直连下载，实测国内 65 KB/s 且经常「连上不给数据」——下载器 20 秒超时重试 8 次，进度条全程 0。现在自动追加国内加速源（官方源仍保留兜底），实测 955 KB/s，24 MB 从「6~11 分钟且可能卡死」降到 26 秒。
- **AI 页左右两栏都可收起**：左栏「新建对话」旁新增收起键，右栏保留贴边把手；收起后内容区自动变宽。
- **输入框聚焦高亮**：点进输入框后输入卡描边点亮，一眼能确认「现在能打字」。

## 优化

- **AI 对话输入区重做**：改成「上层输入框 + 下层工具栏」两层结构，圆角加大，会话设定改为次要描边按钮，发送键换成圆形图标键。
- **发送键与停止键合并**：只留一个圆钮 —— 空闲显示向上箭头（蓝底），生成中显示方块（中性底）。原来那个常驻的灰色「停止」按钮既占位置又像坏了。图标是自绘的：`■` 字符在雅黑里会渲染成一根细竖条，认不出是停止。
- **浅色主题配色统一**：消息气泡、顶部状态条、右侧概要面板原来在「有自定义背景图」时写死深色 `rgba(14,17,22,…)`，而主题的深浅翻转只处理十六进制色值，`rgba()` 完全绕过它 —— 结果浅色主题下永远是深灰气泡压在米白页面上。现在按当前模式分支，深色主题表现不变。
- **输入框字号 13 → 14**，内边距放宽，占位符颜色跟随主题（Qt 的占位符是调色板角色，QSS 管不到）。
- **更新内容弹窗按版本倒序**：最新版本排在最上面，不用滚到底才看到这次改了什么。

## 修复

- **修界面「一动一动」**：顶部状态条原来先写成「实例名 · 端口」的短文本，异步探测端口回来后几十毫秒才补上「（未启动）」后缀 —— 每轮刷新都是「缩 → 伸」，肉眼看到状态条在抽动。现在探测完成才一次性写入最终文本；同时把那段过长的操作指引移进 tooltip，避免把同行末尾内容挤出可视区。
- **修 AI 输入卡点空白处不进输入状态**：输入卡四周内边距和按钮上方空白归容器接鼠标，点了只会让窗口失焦。现在点任何空白都能直接开始打字。
- **修更新内容弹窗一次都没弹过**：对话框构造完没有调用 `exec()`，窗口从未显示。同时修掉「先推进版本号再取说明」的顺序问题 —— 取不到说明时版本号已被提前推进，导致这次更新提示永久丢失。
- 修组件下载 0 字节时只显示「0%」的问题：超过 6 秒没有首包，文案改为「正在连接下载源…」。
- 补若干英文词条漏译（插件告警条按钮、下载等待提示等）。
- 修 `test_theme_i18n` 里三条长期假红的断言（写的是改版前的冷白色值）、`test_local_llm_switch` 的异常退出码。

---

**注意**：AMD 显卡/核显支持（0.8.32 引入）仍在 Intel + NVIDIA 机器上完成验证，**没有 AMD 实机测试**。Radeon 780M 等核显的家族内核兼容属实验性方案，失败时的退化顺序见 `docs/AMD_780M_QWEN_IMAGE.md` 第 10 节。
