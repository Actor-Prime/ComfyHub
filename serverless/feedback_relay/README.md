# ComfyHub 反馈中转 · 部署清单

客户端只 POST 一个公开地址，**密钥全部放在这里（云函数环境变量）**。
一次性配置约 15 分钟，之后零维护。

---

## 一、金数据：建表单 + 拿两个值

1. 注册/登录 <https://jinshuju.net> → 新建**空白表单**，按顺序建 **4 个字段**（顺序决定
   `field_1..field_4`，不要插别的字段）：

   | 顺序 | 字段名 | 类型 | 说明 |
   |---|---|---|---|
   | 1 | 反馈摘要 | 单行文本 | 自动填报告首行 |
   | 2 | 联系方式 | 单行文本 | 用户选填，可能为空 |
   | 3 | 版本 | 单行文本 | 如 0.8.11 |
   | 4 | 诊断信息 | **多行文本** | 完整脱敏报告 |

2. 保存后打开表单 → 分享链接形如 `https://jinshuju.net/f/AbCdEf123` →
   **`AbCdEf123` 就是 `JSJ_FORM_TOKEN`**。

3. 右上角头像 →「个人中心」→「API」→「个人 Access Token」→ 创建 →
   **只显示一次**，复制下来，这是 `JSJ_TOKEN`。

---

## 二、腾讯云：建函数 + 开函数 URL

1. 注册并**实名认证** <https://cloud.tencent.com>（个人认证即可）。
2. 控制台搜索「云函数 SCF」→ 新建函数：
   - 创建方式：**从头开始**
   - 函数类型：**事件函数**
   - 运行环境：**Python 3.10**（3.9/3.12 同样可用，代码只用标准库）
   - 地域：选离你近的（如 `ap-guangzhou`）
   - 提交方法：**在线编辑**，把本目录 `main.py` 全文粘进去
   - 执行超时：改成 **10 秒**
3. 「函数配置」→「环境变量」，加三条：
   ```
   JSJ_FORM_TOKEN = AbCdEf123
   JSJ_TOKEN      = 你的个人 Access Token
   # 选填（想要手机推送就填）：企业微信群机器人 webhook
   # WECOM_WEBHOOK = https://qyapi.weixin.qq.com/cgi-bin/webhook/send?key=xxx
   ```
4. 「函数 URL」→ 开启：
   - 认证类型：**无需认证**（必须，否则客户端调不通）
   - 拿到形如 `https://<函数ID>.scf.tencentcs.com` 的地址
     （腾讯云默认域名，**不需要买域名、不需要备案**）
5. 浏览器打开该地址应返回：
   ```json
   {"ok": true, "service": "comfyhub-feedback-relay"}
   ```

---

## 三、联调一行命令

```bash
curl -X POST "https://<函数ID>.scf.tencentcs.com" \
  -H "Content-Type: application/json" \
  -d '{"version":"0.8.11","contact":"test@example.com","report":"这是一条联通性测试，用来确认整条链路通畅。"}'
```

返回 `{"ok": true}` 且金数据后台出现一条新数据 = 通了。

---

## 四、最后一步

把函数 URL 发我，我填进 `app/feedback.py` 的 `_DEFAULT_ENDPOINT` 重新打包，
客户端「反馈与诊断」里就会多出**「匿名提交」**按钮（未配置时自动隐藏）。

## 费用与安全

- **费用**：腾讯云函数新账号有每月百万次级免费额度，之后按量计费；每月几十条反馈
  的实际成本约等于 0（以控制台计价为准）。
- **防刷**：函数内已做 请求体 ≤300KB、report ≥20 字、单 IP 5 次/分钟、
  实例内 200 次/小时。函数 URL 公开，被扫到会有点垃圾流量，但写不进你别的数据。
- **密钥边界**：`JSJ_TOKEN` 权限 = 你账号下所有表单的读写删，**只能存在这里**；
  一旦怀疑泄露，金数据后台撤销重建，改环境变量即可，客户端不用重新发版。
- **隐私**：客户端只发用户点提交时看到的那段文本（已脱敏：无用户名/机器名/IP/密钥）。
